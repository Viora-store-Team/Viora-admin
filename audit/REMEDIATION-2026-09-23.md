# نتائج إصلاح Viora Admin — 23 سبتمبر 2026

هذا الملف يحدّث تقرير الفحص السابق. النطاق هو لوحة الأدمن المحلية. بطلب المستخدم لم يُعدّل الباك إند ولم يُنشر الموقع.

## التغييرات

- حذف API-STATUS.md الذي احتوى معلومات حساسة. الحذف من ملفات العمل فقط؛ لم تُغيّر بيانات الدخول أو الجلسات أو تاريخ Git.
- تحديث Next.js وeslint-config-next إلى 16.3.6 والتبعيات المتأثرة. نتيجة npm audit الحالية: صفر تنبيهات، بما فيها تبعيات التطوير.
- معالجة خطأ التحقق من الجلسة بشاشة إعادة محاولة، وإخراج المستخدم عند 401 حتى إن كان الرد غير JSON. الطلبات القديمة لا تلغي جلسة أحدث. إضافة مهلة طلب عامة 45 ثانية.
- منع تعليق القوائم عند اختيار الفلتر نفسه، ومعالجة المعرفات غير الصالحة وإعادة تحميل صفحة التفاصيل عند تغيير المعرف.
- إظهار فشل تحميل وحفظ المحتوى، ومنع نشر نص افتراضي بدلاً من محتوى تعذر تحميله. ربط نتيجة الحفظ بالوثيقة الصحيحة، وتنظيف HTML والروابط عبر DOMPurify. إضافة حالة تغييرات غير محفوظة وتحذير مغادرة عبر الروابط أو إغلاق الصفحة.
- إزالة البيانات الافتراضية الصامتة للمناسبات والمجموعات. الميزات غير المتاحة من الخادم تعرض خطأ واضحاً وتعطّل الإنشاء. المحاكاة تتطلب تفعيلها صراحةً في التطوير.
- إظهار النجاح الجزئي عند قبول/رفض متجر وفشل تغيير حالة مالكه؛ لا تظهر رسالة نجاح كامل في هذه الحالة.
- حساب إحصائيات التقييمات والبحث والترتيب من جميع الصفحات، والتحقق من اكتمال العدد. حدّ التحميل 10,000 تقييم أو 100 صفحة؛ ما فوقه يحتاج تجميعاً من الخادم وتظهر رسالة صريحة بدلاً من إجماليات جزئية.
- معالجة التاريخ الناقص من الخادم دون انهيار الصفحة.
- إظهار أخطاء الإشعارات والقراءة، والحفاظ على حالة غير مقروء عند الفشل، وإضافة تحميل المزيد وربط إشعار الطلب بتفاصيله.
- استبدال تحويل صفحة البلاغات بقائمة تعتمد على API الحقيقي مع إظهار عدم توفره.
- تحسين حوارات الواجهة بلوحة المفاتيح وحبس التركيز وEscape، وتمرير خصائص textarea وإتاحة زر إظهار كلمة المرور بلوحة المفاتيح.
- إضافة اختبارات Playwright وCI للبناء وlint والتبعيات والاختبارات. ملفات نتائج Playwright مستثناة من Git وlint.

## التحقق

- npm run build: نجح، بما فيه TypeScript.
- npm run lint: نجح بلا أخطاء أو تحذيرات.
- npm test: نجحت الاختبارات الـ25 على Chrome محلياً (37.3 ثانية).
- npm audit: صفر ثغرات معروفة وقت الفحص.
- git diff --check: نجح.

الاختبارات تستخدم ردود شبكة محاكية وبيانات QA، ولا تثبت أن endpoints الخادم المنشور تعمل. لم تُنفّذ عمليات تعديل على بيانات الأعمال الحقيقية.

## ما بقي خارج النطاق بطلب المستخدم

أخطاء 500 لتفاصيل المتاجر، وendpoints المناسبات والمجموعات والبلاغات والتوصيل الناقصة، تحتاج مستودع الباك إند. الواجهة تعرض فشلها بوضوح؛ لم تُنشأ endpoints محلية توهم بأنها بديل للخادم.

تحسينات عقد OpenAPI، MFA وإبطال الجلسات وHttpOnly وسجل التدقيق، وتجميع التقييمات للبيانات الكبيرة، وفلاتر الطلبات على الخادم، ونسخ المحتوى وحل تعارضات التعديل، وعضوية المجموعات: تبقى أعمالاً تحتاج قراراً وتنفيذاً في الباك إند. لم تُقدّم كإصلاحات مكتملة.

تحديث بطلب المستخدم: أُزيلت ميزتا المناسبات والمجموعات من الواجهة والكود والربط والبيانات التجريبية؛ لم تعودا ضمن المتطلبات المتبقية.

تحديث 2026-09-24: شوهدت صفحة تفاصيل المتجر 623 في جلسة المستخدم تعرض بيانات المتجر والمالك وحالة مقبول/نشط. لم يعد هذا المسار مطلوباً كـendpoint ناقص؛ نتيجة 500 السابقة تاريخية ولا تعمم على الحالة الحالية. تعذرت إعادة تحميل الصفحة آلياً بسبب واجهة إضافة متصفح مفتوحة، ولم يُتحقق من كود HTTP أو جميع المتاجر.

إصلاح القبول والرفض: أزيلت طلبات تفعيل/إيقاف المالك التابعة لقرار مراجعة المتجر. تُستخدم حالة السيرفر كما هي، مع تحديث رسائل التأكيد. نجح البناء وlint وثلاثة اختبارات قبول/رفض بمحاكاة الشبكة قبل تعديل نص الرفض الأخير.
