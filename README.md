# Viora Admin

لوحة مالك المنصة لـ **فيورا** — تطبيق Next.js مستقل.

لوحة التاجر بريبو منفصل: [Viora-Dashboard](https://github.com/Viora-store-Team/Viora-Dashboard).

## التشغيل

```bash
npm install
npm run dev
```

الافتراضي: بيانات تجريبية محلية (mock). لتشغيله على مسارات `/api/admin/*` الحقيقية
حطّ `NEXT_PUBLIC_ADMIN_MOCK=false` بملف `.env` — شوف `.env.example`.
