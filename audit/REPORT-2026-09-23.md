## التحسينات المقترحة بعد إصلاح الأعطال

1. **عقد API واحد محدث:** OpenAPI أو أنواع مولدة مع اختبارات contract؛ ملفات API-STATUS وADMIN-BACKEND-TODO والتعليقات الحالية متناقضة. TypeScript وحده لا يفحص JSON الوارد وقت التشغيل.
2. **إدارة طلبات مشتركة:** timeout عام، إلغاء الطلب السابق، منع رد قديم من استبدال نتائج فلتر أحدث، وتوحيد حالات empty/error/loading. مهلة الدخول موجودة، لكن معظم الطلبات الأخرى بلا حد زمني تطبيقي.
3. **تعطيل الميزات غير المكتملة بوضوح في الإنتاج:** لا fallback صامت إلى بيانات ثابتة. اجعل تشغيل mock اختياراً صريحاً لبيئة تطوير.
4. **اختبارات قبل النشر:** login وforceLogout، pagination والبحث، فشل API، السباق بين حفظ وثيقتين، وتعطل الخطوة الثانية من قبول/رفض المتجر؛ أضف build/lint وأمن التبعيات إلى CI.
5. **واجهة الطلبات:** بحث برقم الطلب وفلترة الحالة والمتجر والتاريخ على السيرفر، وربط إشعارات الطلب بتفاصيله. الصفحة العامة حالياً قائمة مع pagination فقط.
6. **المحتوى:** dirty state وتحذير مغادرة، autosave لمسودة إذا تقرر، ومعالجة version/conflict عند تعديل الصفحة من أدمنين؛ لا تخلط المسودة بالنشر.
7. **قابلية الاستخدام:** focus trap وإرجاع التركيز للنوافذ، Escape متسق، labels للقوائم، وإتاحة زر إظهار كلمة المرور بلوحة المفاتيح. textarea في Input لا يمرر rest أو dir، فيضيع onBlur/autoFocus؛ خلل معروف في الكود يحتاج إصلاحاً.
8. **أمان وتشغيل الأدمن:** إدارة جلسات قابلة للإبطال، MFA إن كان مطلوباً، وسجل تدقيق صادر من الخادم. `GET /admin/audit-logs` وlogout/revoke اقتراحات عقد وليست endpoints تم التأكد من غيابها في هذا الفحص. راجع انتقال الجلسة إلى HttpOnly cookies بتصميم مناسب للـCSRF والدومينات.
9. **عقد الكتالوج:** ربط المناسبات بـcategory IDs حقيقية بدل أسماء ثابتة غير متطابقة في القوالب، وتحديد عضوية المجموعات بالمنتجات أو قواعد بحث؛ حقول المجموعات الحالية لا تكفي وحدها لتعريف هذه العضوية.
